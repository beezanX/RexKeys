# RexKeys

I reached a point where I felt empty inside, so I decided to build a custom split keyboard. because why not?

companies like keeb/ZSA....etc prices are skyrocket but the parts cost way less than that BOM might hit only 30usd or less, so clone this repo, and send it to pcbway or any smt pcb assembly supplier

## Parts (per half)

| what | part | qty |
|---|---|---|
| MCU | MDBT50Q-1MV2 (nRF52840) | 1 |
| RGB driver | IS31FL3733 | 1 |
| Battery charger | BQ24074 | 1 |
| USB | USB-C | 1 |
| Switches (Choc hotswap) | SW_Push | 23 |
| Diodes | 1N4148 | 23 |
| RGB LEDs | LED_RGB | 24 |
| Resistors / caps / inductor | R / C / L | a bunch |

## Firmware
ZMK doesn't support the IS31FL3733, so RGB won't work until I add it. Keys work, lights don't. I'm getting there.
